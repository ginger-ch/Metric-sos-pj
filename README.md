##  Run Locally
1. Clone the repository
   \`\`\`bash
   git clone https://github.com/camt-pathathai/termproject-2025-sos.git
   \`\`\`
2. Install dependencies
   \`\`\`bash
   npm install
   \`\`\`
3. Run with Docker
   \`\`\`bash
   docker compose up
   \`\`\`
4. Open browser at [http://localhost:4000](http://localhost:4000)
